# MobiBing Renewed

MobiBing Marketplace (White • Green • Black • Orange)

Create a premium, modern B2C marketplace website inspired by MobiBing, a Bengaluru startup (2015) that specialized in buying, selling, and exchanging certified pre-owned smartphones, laptops, tablets, and other electronics.

Build a frontend-only MVP using Next.js 15 + Tailwind CSS with reusable components, responsive design, smooth animations, and a startup-quality aesthetic.
